# Uma aventura na Coreia

Jogo estático: abra index.html no navegador. Para publicar no GitHub Pages, envie index.html para um repositório, abra Settings > Pages, selecione Deploy from a branch, escolha main e / (root), e salve. Para publicar na Vercel, importe o mesmo repositório e faça o deploy como site estático, sem comando de build.

Controles: setas ou A/D para andar; espaço, seta para cima ou W para pular. No celular, use os botões da tela.
